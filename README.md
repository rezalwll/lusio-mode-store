# Eleven Style Static Clone

بازسازی استاتیک چندصفحه‌ای Eleven Style با HTML/CSS/JS، داده‌های واقعی فروشگاه و چیدمان واکنش‌گرا.

## اجرا
فایل `index.html` را باز کنید یا پوشه را با Live Server اجرا کنید.

برای بازتولید صفحات از داده‌های فروشگاه:

```bash
node scripts/generate-static.mjs
```

## نکته تصاویر
برای حفظ ظاهر فروشگاه، تصاویر با URL اصلی elevenstyle.ir در HTML ارجاع داده شده‌اند؛ بنابراین برای نمایش تصاویر اتصال اینترنت لازم است.

## صفحات
- صفحه اصلی + استوری‌ها و اسلایدر
- صفحات دسته‌بندی و زیردسته‌ها
- صفحات محصول
- ورود، سبد خرید، تسویه حساب، جستجو و پیگیری سفارش

در مجموع ۱۰۴ صفحه محصول، ۱۸ صفحه دسته‌بندی و صفحات مشترک تولید می‌شوند. سبد خرید، جستجو، فیلتر موبایل، گالری محصول، اسلایدر و فرم پیگیری سفارش با JavaScript کار می‌کنند و سبد خرید در `localStorage` نگه‌داری می‌شود.
